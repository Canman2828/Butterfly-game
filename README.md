Flutter Quest is a VR experience that lets players move around using their joysticks, interact with the environment, and explore a colorful world.
Players can walk around using the Quest controllers, interact with menus using a laser pointer system, and eventually explore different maps we plan to add.
It's designed to make movement feel fun, natural, and easy for anyone to pick up.
